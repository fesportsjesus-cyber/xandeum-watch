# Xandeum pNode Analytics

## Overview

Xandeum pNode Analytics is a dark, neon-accented network monitoring dashboard. It connects to a configured gossip node, displays pNode discovery and network KPIs, and provides derived analytics for node health, response time, and storage utilization.

## User preferences

- Keep the cyberpunk visual language: dark surfaces, cyan/purple accents, monospace telemetry details, and compact information-dense layouts.
- Prefer live or clearly derived node data over decorative placeholder metrics.
- Keep dashboard visualizations responsive and useful on smaller screens.
